# CSE4104-7A-T03-SoulSync-AI-Holistic-Wellness-Mental-Resilience-Preventative-Health-Companion
SoulSync AI is an AI-powered wellness companion that tracks mood, stress, sleep, hydration, activity, and energy. It provides personalized wellness insights, habit tracking, daily routines, weekly summaries, breathing exercises, and reminders to promote healthier lifestyles. It is not a medical device.
